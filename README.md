# Gerald's Doors

Static miniseries landing page and one-image-per-page chapter reader.

Run `python3 build.py` to generate `dist/`. Chapter metadata is in `chapters.json`, with approved images in `chapters/<slug>/`. The header and site style are in `assets/` and `styles.css`.

The first chapter will appear when approved chapter files and metadata are added. The hero copy is provisional pending Darcy's review.

**Deployment is not yet configured.** Cloudflare Worker setup and live visual verification are separate pending steps.
